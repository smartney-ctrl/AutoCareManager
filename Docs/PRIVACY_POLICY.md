# Privacy Policy — AutoCare Manager

AutoCare Manager stores workshop data locally on the device.

## Data collected
- Customer names, phone numbers, email addresses, and addresses entered by the workshop
- Vehicle information entered by the workshop
- Repair job records, parts, labor, and payment records entered by the workshop

## How data is used
Data is used only to run the workshop management features inside the app.

## Sharing
This MVP does not send data to external servers.

## Backups
If the Android device backup feature is enabled, app data may be included in the device backup.
