# Play Store Listing Draft

## App name
AutoCare Manager

## Short description
Auto repair workshop app for customers, vehicles, jobs, parts, labor, and payments.

## Full description
AutoCare Manager helps auto repair shops manage daily operations from one Android app.

### Features
- Save customer records
- Register vehicles
- Create repair jobs
- Track job status
- Add labor and parts costs
- Record payments and balances
- View dashboard totals
- Works offline on one device

### Who it is for
- Mechanics
- Garage owners
- Auto workshops
- Vehicle service centers

### Monetization idea
Start with a free trial, then unlock Pro for unlimited usage and advanced export features.
